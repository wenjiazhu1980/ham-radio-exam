# 业余无线电 A 类模拟考试

中国业余无线电 **A 类** 操作证书模拟考试系统与学习资料。

## 内容

| 文件 | 说明 |
|------|------|
| `index.html` | A 类模拟考试系统（浏览器打开即可使用） |
| `整合版-业余无线电A类知识图谱.html` | A 类知识图谱 |
| `A 类题库.pdf` | 官方题库 PDF |
| `校验报告-官方题库对比.md` | 自建题库与官方 PDF 的校验报告 |

## 使用方法

直接用浏览器打开 `index.html` 即可开始练习，无需安装或构建。

```bash
# 或使用本地静态服务器
npx serve .
# 然后访问 http://localhost:3000
```

## 许可

学习与个人使用。题库内容以国家无线电管理机构发布的官方题库为准。
